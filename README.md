# أخبار طب الأسنان – نموذج أولي (Android)

يجلب يوميًا عناوين الأخبار والتقارير من مواقع طب الأسنان، يعرضها كبطاقات (العنوان + المصدر فقط)، ويرسل إشعارًا يوميًا بالجديد. النقر على البطاقة يفتح الرابط الأصلي.

## المتطلبات
- Android Studio (Koala أو أحدث) و JDK 17
- جهاز/محاكي بنظام Android 8.0 (API 26) أو أعلى، مع اتصال بالإنترنت
- لا حاجة لمفاتيح API ولا لخدمات إشعارات خارجية (الإشعار محلي عبر WorkManager)

## التشغيل
1. افتح مجلد `DentalNews` في Android Studio ودعه يزامن Gradle (سينشئ ملفات gradle wrapper الناقصة تلقائيًا).
2. شغّل التطبيق. عند أول فتح يجلب الأخبار فورًا ويطلب إذن الإشعارات (Android 13+).
3. اختبار المحلل: `./gradlew test`

## البنية (بسيطة عمدًا)
| الملف | الدور |
|---|---|
| `Sources.kt` | **قائمة المصادر** (الاسم + رابط RSS) – عدّلها هنا |
| `RssFetcher.kt` | جلب وتحليل RSS/Atom |
| `NewsRepository.kt` | تخزين محلي (آخر 150 خبرًا) + منطق التحديث |
| `DailyWorker.kt` | WorkManager (كل 24 ساعة، تقريبًا 8 صباحًا) + الإشعار |
| `MainActivity.kt` | واجهة Compose: بطاقات بالعربية (RTL) |

## ملاحظات مهمة
- روابط RSS في `Sources.kt` مأخوذة من أدلة عامة ولم تُختبر آليًا؛ إن لم يعمل مصدر يتجاوزه التطبيق ويكمل بالباقي. الشاشة تعرض عدد المصادر الناجحة.
- لم يُبنَ المشروع ولم يُشغَّل في بيئة التطوير (لا يتوفر Android SDK هناك)، فجرّب البناء وأخبرني بأي خطأ.
- WorkManager لا يضمن توقيتًا دقيقًا (قد يتأخر بسبب توفير الطاقة). لا يُرسل إشعار إذا لم يوجد خبر جديد منذ آخر مرة.
- بعض المواقع قد تحجب الطلبات الآلية أو لا توفر RSS؛ في هذه الحالة يلزم مصدر بديل.

## نسخة الويب (GitHub Pages)
- صفحة `docs/index.html` تعرض الأخبار كبطاقات على الجوال والكمبيوتر.
- يحدّثها `.github/workflows/update-news.yml` يوميًا عبر `scripts/fetch_news.py` (المصادر معرّفة في أعلى الملف).
- تفعيل الصفحة: Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` والمجلد `/docs`.

## بناء APK تلقائيًا
عند كل رفع إلى `main` يبني `.github/workflows/build.yml` التطبيق ويرفع الملف في Actions ← آخر تشغيل ← Artifacts.
